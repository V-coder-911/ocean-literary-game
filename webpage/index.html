ABOUT OCEANQUEST

Smart India Hackathon 2026 — Problem Statement SIH1660

🏆 Smart India Hackathon 2026 — SIH1660

Interactive Gamified Approach to Ocean Literacy

OceanQuest is a browser-based ocean literacy gamification platform developed in response to the Smart India Hackathon 2026 problem statement SIH1660. The platform aims to educate students, fishermen, coastal communities, tourists, and maritime professionals about ocean safety, sustainable practices, and emergency response.

The application enables users to select roles such as fisherman, ship captain, and tourism operator, use simulated ocean information to make decisions, and learn through the consequences of those decisions — earning points for correct choices and receiving educational explanations for incorrect ones.

Organization

Host Organization: Ministry of Earth Sciences / INCOIS (Indian National Centre for Ocean Information Services)

INCOIS provides ocean information and advisory services to society, industry, government agencies, and the scientific community. OceanQuest's architecture is designed to allow seamless integration with real INCOIS APIs and ocean data once available.

Technology Stack

HTML5 CSS3 Vanilla JavaScript SVG Maps CSS Animations Glassmorphism UI Responsive Design Simulated Ocean API

Backend-ready architecture: Python/Flask + SQLite (prototype) → PostgreSQL (production). Modular design allows INCOIS API integration and admin-managed content updates post-hackathon.

Game Flow

Landing → Login/Guest → Dashboard → Choose Role → Tutorial → Mission → Ocean Data → Decision → Evaluation → XP + Points → Learning → Next Mission → Level Up → Leaderboard
